# 🛡️️ Advanced Penetration Testing Wordlist Generator

[![Python Version](https://img.shields.io/badge/Python-3.x-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![GUI: Tkinter](https://img.shields.io/badge/GUI-Tkinter-orange.svg)](https://docs.python.org/3/library/tkinter.html)

A sleek, high-performance GUI tool designed for penetration testers and security professionals to generate customized, high-probability password dictionaries. Built with Python and Tkinter, it features a modern **Dark Tech / Cyberpunk** interface complete with **real-time sample streaming** and a **live variation count estimator**.

---

## ✨ Key Features

* **🎨 Modern Cyberpunk GUI:** Designed with a polished dark slate theme, custom input fields, and high-contrast cyan highlights for reduced eye strain during late-night lab sessions.
* **⚡ Live Total Estimator & Real-Time Preview:** Instantly calculates the total expected wordlist size and displays a live stream of sample variations as you type seed words or toggle rules.
* **🔤 Multi-Layer Mutation Engine:**
  * **Case & Reversal Mutations:** Automatically generates original, lowercase, uppercase, capitalized, reversed, and standard leet speak (`4dm1n`) forms.
  * **Numeric Ranges & Positioning:** Injects custom number ranges (e.g., `0-99`) as suffixes, prefixes, or injected into the middle of words.
  * **Symbol Injection & Positioning:** Selectable symbol sets (`!@#$`) applied flexibly across suffix, prefix, or middle positions.
* **📂 Flexible Input/Output:** Type or paste base seed words directly into the text box, or load massive word lists from external `.txt` files with automatic duplicate elimination.
